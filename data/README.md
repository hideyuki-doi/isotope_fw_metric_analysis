# Data

Place the four IsoFresh CSV files here (semicolon-delimited, as distributed):

- `IsoFresh_Ecosystem.csv`
- `IsoFresh_FoodWeb.csv`
- `IsoFresh_Isotope_Fish.csv`
- `IsoFresh_Isotope_Other.csv`

Raw data are not tracked in this repository. WorldClim 2.1 and HydroLAKES are downloaded automatically by `R/01_network_analysis_full_pipeline.R`.
